리포지토리 문서 자동 생성 및 유지 도구

📌 핵심 개념
OpenWiki는 에이전트를 위해 특별히 설계된 CLI 도구입니다. 코드 저장소의 문서를 자동으로 생성하고, GitHub Actions로 지속적으로 업데이트합니다.

🎯 OpenWiki를 만든 이유

핵심 질문

CEO가 던진 질문: "다음 큰 AI 혁신은 무엇인가?"

2023년: OpenClaw (개인 에이전트)
2024년: General Purpose Memory (범용 메모리)

기술적 배경

현대의 LLM과 에이전트 아키텍처로 이제 범용 메모리 솔루션이 가능해졌습니다.

코드 기반 문서를 시작으로, 향후 다양한 메모리 영역으로 확장:

  • 코드 저장소 문서
  • 조직 정보
  • 시스템 설계
  • 비즈니스 규칙

💡 3가지 핵심 가설

1️⃣ 에이전트를 위해 설계

기존 문서와 에이전트 문서는 완전히 다릅니다:

기존 (인간 중심):
• 스토리 구조와 흐름
• 스크린샷과 비디오
• 연속적인 내러티브
• 맥락적 이해 필요
에이전트 (OpenWiki):
✅ 자체 완결적 콘텐츠 (snippets)
✅ 예측 가능하고 정확한 헤딩
✅ 컨텍스트 윈도우 최적화
✅ 필터링과 검색 지원

2️⃣ 설정 및 실행의 간편성

목표: 개발자가 쉽게 시작할 수 있도록

설치:
npm install openwiki
초기화:
open wiki init
자동 생성:
• agents.md 또는 claw.md 수정
• GitHub Actions 워크플로우 추가
• 매일 실행되는 cron job

3️⃣ 자동 업데이트

요구사항:
• 코드 변경 시 문서 자동 업데이트
• 인간의 추가 작업 없음
• GitHub Actions로 자동화

🏗️ OpenWiki의 생성 구조

생성 파일

wiki/
├── quickstart.md
│   # 저수준 개요 (에이전트 진입점)
├── CHANGELOG.md
│   # 변경 이력
├── INDEX.md
│   # 파일 색인
├── [topic-folders]/
│   ├── [topic].md
│   │   # OKF 형식의 마크다운
│   └── index.md
       # 폴더 색인
└── agents.md
   # 에이전트 인식

🔧 CLI 사용법

커맨드 1: open wiki init

저장소에서 최초 1회 실행하여 모든 것을 설정합니다.

# 설치
npm install openwiki
# 초기화 (대화형 설정)
open wiki init
# 자동으로 생성되는 것들:
• agents.md 또는 claw.md 수정
• GitHub Actions 워크플로우
• 매일 실행되는 cron job

커맨드 2: open wiki update

GitHub Actions에서 매일 자동으로 실행됩니다.

# 동작 순서
1️⃣ Git 히스토리 분석
2️⃣ 변경사항 감지
3️⃣ 문서 자동 업데이트
4️⃣ PR 자동 생성

📊 성능 평가

벤치마크 결과

Deep Seek 벤치마크를 통한 초기 평가

성공 작업: 7-8개 → 9-10개 (+20%)
도구 호출: 기준선 → ↓ 감소
토큰 소비: 기준선 → ↓ 크게 감소
핵심 발견
동일하거나 더 나은 결과를 훨씬 적은 토큰으로 달성했습니다.

🚀 향후 계획

1. 더 나은 프롬프팅

• Evals 강화
• 더 큰 저장소 지원
• 자체 업데이트 능력 향상

2. 검색 및 검색 도구

전용 검색 도구로 에이전트가 더 효율적으로 활용

• 전용 검색 도구
• 고급 필터링
• 동적 쿼리 처리

3. 범위 확대

조직 정보, 시스템 설계, 비즈니스 규칙 등으로 확장 예정

결론

에이전트 시대의 새로운 문서 패러다임
OpenWiki는 단순한 문서 생성 도구가 아닙니다. 에이전트 중심의 문서 철학을 실현합니다. 이제 시작할 시간입니다.
